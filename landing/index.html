The full stack, rebuilt for privacy

Six layers, each designed so no single party can surveil your team.

🧅

Tor Transport

No IP exposed, no relay, both endpoints are ephemeral v3 onion services. Tor circuit prevents traffic analysis.

🔐

Noise_XX E2E

X25519 key exchange, ChaCha20-Poly1305 AEAD on every byte. HKDF-SHA256 derivation. No TLS, no OpenSSL dependency.

🪪

ENSv2 Identity

*.weave.eth subnames on Ethereum. ERC-5564 stealth addresses. Wildcard resolver — one deployment for all orgs.

📦

Arkiv Messages

Decentralized message storage. Client-side encrypted before upload. Time-scoped fetch. Key versions track rotations.

⛓️

On-chain Roles

EAC 256-bit bitmap. Custom org roles in nybbles 16–63 via WeaveRoleRegistry. Grant and revoke with a single tx.

🔒

CRE Signing

Go WASM confidential workflow. ENS transactions signed inside CRE — the private key never reaches the frontend process.
