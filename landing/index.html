Privacy guarantees

Not promises — cryptographic properties enforced by the protocol.

Property Mechanism Who could break it
✓ Your IP address Both endpoints are Tor v3 onion services. No IP ever touches a relay. Global adversary doing Tor traffic correlation (theoretical)
✓ Message content Noise_XX E2E — ChaCha20-Poly1305. No server decrypts. Compromise of endpoint device
✓ Call metadata ERC-5564 stealth addressing — caller uses one-time pubkey per session. On-chain analysis linking ephemeral keys (hard with secp256k1)
✓ Your spending key CRE HandlerInTee — key stays in AWS Nitro enclave. Operators see only "a scan ran." Hardware-level TEE compromise (nation-state)
✓ File content ChaCha20-Poly1305 encrypted before IPFS. IPFS nodes see only ciphertext. Recipient device compromise
✓ Who you talk to DHT lookup encrypted; Nostr relay sees only gift-wrapped ciphertext. Relay operator correlating timing (mitigated by random delays)
