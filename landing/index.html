Solution

Everything Teams has. Nothing Teams leaks.

Full feature parity with Microsoft Teams — zero external server dependency, zero surveillance surface.

🧅

Zero IP Exposure

Both endpoints are Tor v3 onion services. No STUN, no TURN, no relay. Your IP never touches any server.

🔐

Noise_XX Encryption

X25519 key exchange + ChaCha20-Poly1305 AEAD on every connection. Implemented from scratch on @noble/curves.

👤

ENSv2 On-Chain Identity

Every user is alice.weave.eth. Every org is acme.weave.eth. Roles stored in a 256-bit EAC bitmap on Ethereum.

🗺️

Destroyed Graph

ERC-5564 stealth addresses — one-time keys per session. The communication graph cannot be reconstructed.

📦

Arkiv Message Storage

Messages stored on Arkiv — decentralized data layer on Ethereum. Ciphertext only. Per-channel symmetric keys, rotated on membership change.

🔒

CRE Confidential Writes

ENS transactions signed in a Go WASM confidential workflow. The private key never touches the frontend.
